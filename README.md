# Noolite NooHub — интеграция для Home Assistant

Кастомная интеграция для [Home Assistant](https://www.home-assistant.io/), которая подключает устройства [Noolite](https://noo.by) через контроллер **NooHub**.

## Возможности

- Автоматическое обнаружение устройств с NooHub-контроллера
- Поддержка освещения: включение/выключение, яркость, RGB-цвет
- Поддержка переключателей
- Оптимистичное управление TX-устройствами (без обратной связи)
- Настройка через UI (Config Flow), без правки YAML
- Опрос состояния каждые 30 секунд для устройств с обратной связью

## Поддерживаемые платформы

| Платформа | Тип устройства в NooHub | Поддерживаемые функции |
|-----------|-------------------------|------------------------|
| `light`   | `block` / `light`       | on/off, яркость (0–100%), RGB |
| `switch`  | `block` / `switch`      | on/off |

## Требования

- Home Assistant 2023.1 или новее
- Контроллер **NooHub** с доступным HTTP(S) API
- Учётные данные для доступа к API контроллера (HTTP Digest Auth)

## Установка

### Через HACS (рекомендуется)

1. Откройте HACS → Интеграции → меню (три точки) → **Пользовательские репозитории**
2. Добавьте URL этого репозитория, тип — **Интеграция**
3. Найдите **Noolite NooHub** и установите
4. Перезапустите Home Assistant

### Вручную

1. Скопируйте папку `custom_components/noolite` в `<config>/custom_components/noolite`
2. Перезапустите Home Assistant

## Настройка

1. Перейдите в **Настройки → Устройства и службы → Добавить интеграцию**
2. Найдите **Noolite NooHub**
3. Заполните форму:

| Поле | Описание | По умолчанию |
|------|----------|--------------|
| **Адрес контроллера** | IP-адрес или hostname NooHub | — |
| **Логин** | Имя пользователя для API | — |
| **Пароль** | Пароль для API | — |
| **Протокол** | `http` или `https` | `http` |
| **Базовый путь API** | Путь до API-эндпоинта | `/api` |

После успешного подключения все устройства будут добавлены автоматически.

## Как работает интеграция

### Опрос устройств

Интеграция использует `DataUpdateCoordinator` и опрашивает NooHub каждые **30 секунд**:

1. `get_devices` — получает список всех устройств и их метаданные
2. `get_state` — получает актуальное состояние для устройств с флагом `retrievable: true`

### TX-устройства (без обратной связи)

Устройства с `retrievable: false` (чистые TX-передатчики Noolite) управляются **оптимистично**: после отправки команды состояние обновляется локально без подтверждения от устройства.

### Аутентификация

API NooHub использует **HTTP Digest Authentication**.

## Устранение неполадок

**Не удаётся подключиться** — проверьте, что NooHub доступен по сети, логин/пароль верны, протокол и путь API совпадают с настройками контроллера.

**Устройства не появляются** — убедитесь, что в NooHub устройства имеют тип `block` и подтип `light` или `switch`. Другие типы текущей версией интеграции не поддерживаются.

**Состояние не обновляется** — устройство может быть TX-only (`retrievable: false`). Состояние таких устройств хранится локально и сбрасывается при перезапуске HA.
