# API контроллера NooHub

*Актуально к ПО v1.136*

Техподдержка в Телеграм [@tech\_support\_noolite](https://t.me/tech_support_noolite)

| Параметр | Описание |
| ----- | ----- |
| Максимальное время ожидания ответа | \~9 секунд |
| Максимальный размер JSON | \~60 Кбайт |
| Максимальное количество устройств | 64 |
| Максимальное количество комнат | 20 |
| Максимальное количество сценариев | 30 |
| Максимальное количество условий на сценарий | 5 |
| Максимальное количество исполнителей на сценарий | 20 |
| Максимальный размер названия устройств, комнат, сценариев, логин/пароль авторизации, пароль Wi-Fi | 20 символов \- кириллица 40 символов \- латиница |

Пример полного запроса к API контроллера

| POST /api HTTP/1.1Host: 192.168.1.2Content-Type: application/jsonAccept: application/jsonContent-Length: 25{"action": "get\_devices"} |
| :---- |

В ответе на запросы есть два параметра

| {  "success":true | false,  "message":"ok",  ...} |
| :---- |

| Поле | Описание | Тип данных |
| :---: | :---: | :---: |
| success | Успешность выполнения запроса | bool |
| message | Сообщение к ответу на запрос ([см. таблицу](#значения-параметра-message)) | String |

# Значения параметра message {#значения-параметра-message}

| Значение | Описание | Решение |
| :---: | :---: | ----- |
| ok | Запрос выполнен |  |
| timeout | Превышено время ожидания ответа |  |
| max\_number\_device | Достигнуто максимальное количество устройств | Удалите некоторые устройства |
| no\_model\_id | Неправильный идентификатор модели  model\_id |  |
| error\_type | Неизвестное значение в поле type |  |
| device\_already\_exists | Устройство уже привязано (Noolite-F) |  |
| device\_not\_allowed | Устройство не поддерживается |  |
| error\_bind | Произошла ошибка во время привязки | Попробуйте выполнить привязку снова |
| bind\_confirm | Необходимо подтвердить привязку устройства |  |
| unbind\_confirm | Необходимо подтвердить отвязку устройства |  |
| unbind\_error | Произошла ошибка во время отвязки | Возможно не включили сервисный режим на устройстве Noolite-F |
| room\_already\_exists | Комната с таким именем уже существует | Придумайте другое имя |
| room\_limit | Достигнут лимит комнат | Удалите комнату |
| room\_not\_found | Комнаты не существует | Проверьте идентификатор комнаты |
| bind\_ok | Привязка выполнена |  |
| unbind\_ok | Отвязка выполнена |  |
| no\_device | Устройства не существует |  |
| error | Ошибка |  |
| limit\_scens | Лимит сценариев | Удалите некоторые сценарии |
| no\_scen\_id | Сценария не существует |  |
| no\_conds\_actions | Нет массива conds\[\] или actions\[\] |  |
| limit\_conds  | Достигнут лимит условий сценария | Удалите некоторые условия |
| limit\_actions  | Достигнут лимит исполнителей сценария | Удалите некоторых исполнителей |

# Привязка устройств Noolite {#привязка-устройств-noolite}

Пример запроса

| {  "action":"bind",  "type":"ntx",  "model\_id":0,  "name":"Люстра",  "room\_id": 0} |
| :---- |

| Параметр | Описание | Тип данных |
| :---: | ----- | :---: |
| action | bind | String |
| type | протокол привязываемого устройства:  ntx \- устройство без обратной связи Noolite  ntxf \- устройство с обратной связью Nooolite-F  nrx \- устройство Noolite-RX | String |
| model\_id[^1] | номер модели устройства | uint8\_t |
| name | Название устройства  (может быть урезано при привышении лимита) | String |
| room\_id | Идентификатор комнаты (см. раздел Добавления комнат) | uint8\_t |

Идентификаторы силовых блоков Noolite TX

| model\_id | Модель блока Noolite TX |
| :---: | :---: |
| 0 | SU-1-xxx |
| 1 | SB-1-100 |
| 2 | SR-2-1000 |
| 3 | SD-3-60/120 |
| 4 | SD-1-60/120 |
| 5 | SD-1-010 |
| 22 | ST-111-xxx |
| 23 | SL-111-xxx |

Идентификаторы устройств Noolite RX

| model\_id | Модель устройства Noolite RX |
| :---: | :---: |
| 15 | PM-112 |
| 16 | PT-112 |
| 17 | PT-111 |
| 18 | PL-111 |
| 19 | DS-1 |
| 20 | WS-1 |
| 21 | PB/PG/PK/PN/PU |

Пример ответа

| {  "success": true,  "message":"bind\_ok",  "device\_id":"xxxxxxxxxx",  "model\_name": "SU-1-200" } |
| :---- |

| Параметр | Описание | Тип данных |
| :---: | :---: | :---: |
| message |  bind\_ok bind\_confirm  ([см. таблицу](#значения-параметра-message)) | String |
| device\_id[^2] | Идентификатор устройства | String |
| model\_name | Название модели устройства | String |

---

Пример ответа

| {  "success": true,  "message":"ok",  "devices": \[     {      "id": "817db949cc",      "name": "Подсветка",      "room": "Кухня",      "model": "SRF 1-3000-M",      "type": "block",       "subtype": "switch",      "retrievable": true,      "reportable": true,      "skills":\[        "on",        "brightness",        ...      \],      "sensors":\[         "tmp",        "hmd",         ...       \]    },     ...  \]} |
| :---- |

| Параметр | Описание, значения | Тип возвращаемых или устанавливаемых данных |
| :---: | ----- | :---: |
| devices | Массив с устройствами пользователя | Array of objects |
| Объект devices |  |  |
| id | Идентификатор устройства | String |

| model | Название модели устройства | String |

| protocol | noolite/http | String |
| ip[^8] | IP \- адрес устройства в сети | String |
| noolite\_mode[^9] | Noolite TX \- 0, Noolite RX \- 1, Noolite F-TX \- 2 | int |
| retrievable | Доступен ли для данного устройства запрос состояний | bool |

| thermostat | Возможность устанавливать температуру | uint8\_t |

| overflow\_color | Возможность включения перелива цветов | bool |
| speed\_mode\_switch | Возможность переключения скорости перелива цветов | bool |
| pause | Пауза (для SRF-1-1000-R) | bool |
| open\_close | Открыть true или закрыть false (для SRF-1-1000-R) | bool |
| {name, min, max} | Объект name \- имя умения min \- минимальное значение max \- максимальное значение | object |

Пример запроса

| {  "action":"set\_state",  "devices":\[    {      "id": "xxxxxxxxxx",      "state": {        "on": false,        "brightness": 45,        ...      }    },    ...  \]} |
| :---- |

| Параметр/ значение | Описание | Тип данных |
| :---: | :---: | :---: |
| action | set\_state | String |

| Объект устройства |  |  |
| id | Идентификатор устройства | String |
| no\_device | Если устройства не существует или было удалено | bool |
| Объект state |  |  |
| Параметры в данном объекте полностью соответствуют [возможностям устройства (skills)](#bookmark=id.mtzceup1zvs0) |  |  |

Пример ответа

| {  "success":true,  "devices":\[    {      "id":"xxxxxxxxxx",      "result":true    },    ...  \]} |
| :---- |

| Параметр | Описание | Тип данных |
| :---: | :---: | :---: |
| devices | Массив с устройствами | Array of objects |
| Объект устройства |  |  |
| id | Идентификатор устройства | String |
| result | Результат выполнения команды (для Noolite TX всегда true, для Noolite-F соответственно если блок корректно ответил на запрос) | bool |
| no\_device | Если устройства не существует или было удалено | bool |

Если устройств в массиве devices больше одного, тогда сразу возвращается ложный ответ во всех устройствах в массиве {result: true}
